# zapret-discord-youtube

Набор BAT-скриптов, конфигураций и компонентов для работы с ограничениями сетевого доступа к Discord и YouTube в Windows. Результат зависит от сети, провайдера и выбранной стратегии; универсальная работоспособность не гарантируется.

Проект основан на исходном репозитории [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) и использует материалы [zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle) и [zapret](https://github.com/bol-van/zapret).

## Быстрый старт

1. Откройте релиз [1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2) и скачайте опубликованный архив проекта.
2. В свойствах архива Windows при наличии установите флажок **«Разблокировать»**. При использовании 7-Zip или PeaZip этот шаг обычно не требуется.
3. Распакуйте архив в папку без кириллицы, пробелов и нестандартных символов, например:

   ```text
   C:\zapret\
   ```

4. Для ручного запуска от имени администратора откройте нужный файл `general*.bat` и выберите стратегию, если скрипт показывает меню.
5. Проверьте работу Discord и YouTube. Если выбранная стратегия не помогает, завершите её и протестируйте другой вариант `general*.bat`.

Перед запуском проверьте происхождение архива. В составе проекта используется WinDivert — системный компонент для перехвата и обработки сетевого трафика. Некоторые защитные программы могут классифицировать его как инструмент повышенного риска. Подробности приведены в документации [zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B).

## Требования и подготовка

Проект предназначен для Windows. Для запуска стратегий и управления службой могут потребоваться права администратора.

Для отдельных ресурсов в README исходного проекта рекомендуется настроить Secure DNS или DNS over HTTPS:

- в Chrome откройте настройки безопасного DNS и выберите конкретного поставщика;
- в Firefox включите DNS через HTTPS, выберите ручного поставщика и укажите адрес, например `https://dns.google/dns-query`;
- в Windows 11 Secure DNS настраивается в системных параметрах;
- на роутере Keenetic проверьте параметр **«Транзит запросов»**, поскольку его отключение может мешать работе Secure DNS на компьютере.

## Запуск и настройка

### Ручной запуск стратегий

`general*.bat` предназначены для ручного запуска стратегий. В каталоге могут быть варианты с названиями `ALT`, `FAKE`, `SIMPLE FAKE`, `EXP` и другие конфигурации. Выбор зависит от сети и провайдера: если один вариант не работает, остановите его и проверьте другой.

При обычном запуске стратегии должен появиться процесс `winws.exe`. Не запускайте несколько стратегий одновременно.

### Работа через службу Windows

`service.bat` предназначен для управления службой и диагностики. Доступные пункты меню зависят от содержимого версии и включают следующие операции:

- `Install Service` — добавление выбранной стратегии в автозапуск Windows;
- `Remove Services` — удаление созданных служб и WinDivert;
- `Check Status` — просмотр состояния служб и активной конфигурации;
- `Run Diagnostics` — проверка распространённых причин неправильной работы;
- `Run Tests` — запуск тестов доступных стратегий;
- `Game Filter` — управление обработкой игрового трафика через UDP/TCP на соответствующих портах;
- `IPSet Filter` — управление фильтрацией адресов из `ipset-all.txt`;
- `Replace active fakes` — выбор другого fake-файла из `bin`;
- `Update IPSet List` — обновление `ipset-all.txt`;
- `Update Hosts File` — обновление hosts для отдельных Telegram-ресурсов и голосовых подключений Discord;
- `Auto-Update Check` и `Check for Updates` — автоматическая и ручная проверка обновлений.

Ручной запуск `general*.bat` и установка службы — разные способы работы. После выбора подходящей стратегии её можно установить через `service.bat` → `Install Service`. Для удаления службы используйте `Remove Services`.

### IPSet Filter

Режим фильтрации может иметь следующие состояния:

- `none` — IP-адреса не используются для фильтрации;
- `loaded` — проверяются адреса из списка;
- `any` — под фильтрацию попадает любой IP.

После изменения параметров может потребоваться повторный запуск активной стратегии. Режим `ipset any` способен затрагивать соединения, которые не должны обрабатываться, поэтому его не следует использовать постоянно без необходимости.

### Тестирование стратегий

В `service.bat` → `Run Tests` доступны:

- **Standard tests** — проверка ресурсов из `utils/targets.txt`;
- **DPI checkers** — дополнительные проверки DPI для разных сетевых условий.

## Устранение проблем

### После запуска `general*.bat` не появляется результат

Проверьте, появился ли процесс `winws.exe`. Если он не запускается или сразу завершается:

1. закройте текущий скрипт;
2. запустите его от имени администратора;
3. попробуйте другую стратегию;
4. выполните `service.bat` → `Run Diagnostics`.

Дополнительное обсуждение: [Issue #522](https://github.com/Flowseal/zapret-discord-youtube/issues/522).

### Ни одна стратегия не работает

Откройте командную строку от имени администратора и выполните:

```cmd
netsh winsock reset
netsh int ip reset all
netsh winhttp reset proxy
ipconfig /flushdns
```

Перезагрузите компьютер и повторите проверку нескольких стратегий.

### Не работает Telegram Web или голосовой Discord

Откройте `service.bat` → `Update Hosts File`. Если скрипт предлагает изменить hosts вручную:

1. скопируйте предложенное содержимое;
2. откройте файл `hosts` с правами администратора;
3. добавьте необходимые строки;
4. сохраните файл и повторите проверку подключения.

### Не подключается Discord

Проверьте Secure DNS, выполните `service.bat` → `Run Diagnostics`, очистите кэш Discord и протестируйте Discord в браузере: [discord.com/app](https://discord.com/app). Если браузерная версия работает, причина может быть связана с локальными данными приложения. Также проверьте другую стратегию.

Дополнительное обсуждение: [Discussion #252](https://github.com/Flowseal/zapret-discord-youtube/discussions/252).

### Не открывается YouTube

Проверьте настройку Secure DNS, смените стратегию и временно исключите влияние стороннего блокировщика рекламы. Дополнительное обсуждение: [Discussion #251](https://github.com/Flowseal/zapret-discord-youtube/discussions/251).

### Не работают игры или конфликтует приложение

Обновите IPSet через `service.bat`, проверьте `Game Filter` и `IPSet Filter`, затем протестируйте другую стратегию. Чтобы исключить влияние фильтрации, временно установите `Game Filter` в `disabled`, а `IPSet Filter` — в `none`.

Если игре нужны определённые адреса, их можно добавить в `ipset-all.txt`. Обсуждение проблем с конкретными играми доступно в [Discussions](https://github.com/Flowseal/zapret-discord-youtube/discussions).

### Стратегия перестала работать

Сетевые условия могут измениться. Проверьте другую стратегию, запустите `Run Diagnostics`, обновите IPSet и hosts, затем повторите тестирование. Описание параметров доступно в документации оригинального [zapret](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

### Полное обновление

1. Сохраните собственные изменения и пользовательские списки.
2. Перезагрузите Windows.
3. Откройте `service.bat` → `Remove Services`.
4. Выполните `Run Diagnostics`.
5. Удалите старую папку проекта.
6. Скачайте архив из раздела [Releases](https://github.com/Flowseal/zapret-discord-youtube/releases).
7. При необходимости разблокируйте архив в свойствах Windows.
8. Распакуйте новую версию в отдельную папку.
9. Протестируйте несколько `general`-стратегий.
10. Для выбранной конфигурации при необходимости выполните `Install Service`.

### WinDivert остался в службах

Откройте `cmd` и выполните:

```cmd
driverquery | find "Divert"
```

Найдите имя соответствующей службы и выполните:

```cmd
sc stop название_службы
sc delete название_службы
```

Сведения о специальной конфигурации WinDivert приведены в [zapret-win-bundle/windivert-hide](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide). Для Windows 7 варианты `WinDivert.dll` и `WinDivert64.sys` доступны в разделе [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

## Пользовательские списки

Дополнительные домены и IP-адреса можно указывать в следующих файлах:

- `list-general-user.txt` — пользовательские домены и поддомены;
- `list-exclude-user.txt` — домены-исключения;
- `ipset-all.txt` — IP-адреса и подсети;
- `ipset-exclude-user.txt` — исключения для IP-адресов и подсетей.

Файлы с суффиксом `-user` создаются автоматически при первом запуске `zapret` или `service.bat`.
